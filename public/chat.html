Where does authentication happen?

smart_toy
Authentication in this repository is primarily handled through NextAuth.js. The main configuration defines providers and callbacks in the auth setup. The auth() helper is exposed for server-side usage. Route protection and session validation on edge requests are handled by middleware.ts.

How is session data accessed in server components?

smart_toy
Server components can access session data using the imported auth() function from lib/auth.ts. Because server components run on the server, they can await this function directly without needing a context provider. In client components, you would use the useSession() hook provided by next-auth/react.
